# How to get the data

The data file is about 45 MB. That is too big for GitHub, so it is not in this repo. Downloading it takes about one minute :)

## Steps

1. Open this page: https://archive.ics.uci.edu/dataset/502/online+retail+ii
2. Click the **Download** button. You get a zip file.
3. Open the zip. Inside there is one file: `online_retail_II.xlsx`
4. Put that file here, in this folder (`data/raw/`).

That is all.
